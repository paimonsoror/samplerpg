# Echoes of Aster

A 16-bit style RPG tech demo that runs in the browser: Mode 7 title screen,
town exploration, ATB battles with combo techs, and SNES-style music. Every
pixel, tile, monster, song and sound effect is generated by code at load;
there are no image or audio files and nothing to install.

## Play it

```bash
git clone https://github.com/paimonsoror/samplerpg.git
cd samplerpg
python3 -m http.server 8765      # Windows: python -m http.server 8765
```

Open http://127.0.0.1:8765/, click the game screen, and press **Z** or **Enter**.

| Key | Action |
|---|---|
| Arrows / WASD | move |
| Z / Enter | confirm, talk |
| X / Esc | cancel (hold to dash) |
| C | menu |
