# Run Echoes of Aster

## What this project is

A zero-dependency static web game: `index.html` plus eight classic scripts in
`src/`. There is no package.json, no bundler and nothing to install to *play*
it. Every sprite, tile, song and sound effect is generated by code at load;
the only network request is a Google Fonts stylesheet for the hint text,
which falls back to a monospace font offline.

```
index.html   page shell: 256x224 canvas, hint line, touch pad, <script> tags
src/core.js     screen, input, bitmap font, windows
src/audio.js    WebAudio synth + music
src/art.js      procedural sprites/tiles
src/world.js    maps
src/data.js     party, items, enemies, events
src/field.js    overworld/town exploration
src/battle.js   ATB battle system
src/main.js     scenes, Mode 7 title, game loop (must load last)
```

The scripts share globals and **must load in the order index.html lists
them**. Don't convert them to ES modules or reorder the tags.

## 1. Get the code

```bash
git clone https://github.com/paimonsoror/samplerpg.git
cd samplerpg
```

## 2. Serve it

Run from the repo root. The server blocks, so start it in the background (or
in its own terminal).

```bash
python3 -m http.server 8765 --bind 127.0.0.1      # macOS / Linux
python -m http.server 8765 --bind 127.0.0.1       # Windows (or: py -3 -m ...)
npx --yes http-server -p 8765 -a 127.0.0.1 -c-1   # no Python, has Node
```

If 8765 is taken, pick another port and use it everywhere below.

## 3. Check it's up

```bash
for p in "" src/core.js src/audio.js src/art.js src/world.js src/data.js src/field.js src/battle.js src/main.js; do
  printf '%s %s\n' "$(curl -s -o /dev/null -w '%{http_code}' "http://127.0.0.1:8765/$p")" "/$p"
done                                   # every line should be 200
for f in src/*.js; do node --check "$f" || echo "SYNTAX ERROR in $f"; done   # optional, needs Node
```

## 4. Play it (human)

Open http://127.0.0.1:8765/ in Chrome, Edge, Firefox or Safari. **Click the
game screen once**: that focuses it and lets the browser start audio (sound
stays silent until the first click or keypress, which is expected).

| Key | Action |
|---|---|
| Arrows / WASD | move, menu cursor |
| Z / Enter / Space | confirm, talk |
| X / Esc | cancel; hold to dash |
| C / M / Tab | field menu |

On phones/tablets an on-screen D-pad and A/B/MENU buttons appear instead.

## 5. Drive it (agent)

Launching isn't enough: drive the game and look at the result. The included
`smoke.cjs` (next to this file) clicks the screen, starts a New Game, advances
the intro, walks, opens the menu, screenshots the canvas after each step, and
asserts on the game's `scene` global. It exits 1 on any uncaught page error,
wrong scene, or blank canvas.

Install Playwright **outside the repo** so no `node_modules` lands in it:

```bash
REPO="$PWD"
mkdir -p /tmp/aster-pw && cd /tmp/aster-pw && npm init -y >/dev/null
npm i playwright && npx playwright install chromium
# Linux containers also need system libs (root): npx playwright install --with-deps chromium
NODE_PATH=/tmp/aster-pw/node_modules node "$REPO/.claude/skills/run-echoes-of-aster/smoke.cjs" \
  http://127.0.0.1:8765/ /tmp/aster-shots
```

If Chrome or Edge is already installed, skip the browser download:
`npm i playwright-core` and set `PW_CHANNEL=chrome` (or `msedge`).

On Windows PowerShell:
`$env:NODE_PATH="$PWD\node_modules"; $env:PW_CHANNEL="msedge"; node <repo>\.claude\skills\run-echoes-of-aster\smoke.cjs`

Expected output is five `ok` lines and `SMOKE PASSED`. **Then open the PNGs
and look at them:**

| Shot | Should show |
|---|---|
| `1-title` | Mode 7 landscape, "ECHOES of ASTER" logo, New Game / Sound menu |
| `2-new-game` | "Larkspur Village" banner, Sera's first line in a dialogue box |
| `3-intro-advanced` | village with houses, a well, NPCs, red-haired hero; no dialogue box |
| `4-walked` | camera scrolled down/right; hero leading Sera and Tobin in a line |
| `5-menu` | party menu: Arden, Sera, Tobin (Lv 5), items, gold, time |

The smoke script only needs the game to be *served*; for your own probes,
`page.evaluate('scene')` returns `'title' | 'field' | 'battle' | 'gameover' | 'ending'`.

## Gotchas

- `404 /favicon.ico` in the server log or console is harmless; there is no favicon.
- Title input is ignored for the first 30 frames and the menu appears around
  frame 70 (~1.2 s). Press keys too early and nothing happens.
- A one-shot `chrome --headless --screenshot` captures the Mode 7 background
  before the logo and menu slide in. That's timing, not a bug; use the
  Playwright script for real checks.
- `index.html` has no `<!doctype>`/`<head>` (it started life as a claude.ai
  artifact, hence the `claude:viewport-fit-sides` meta). It renders fine
  as-is; don't restructure it while just trying to run the game.
- WSL: a server started inside WSL is reachable from the Windows browser at
  `127.0.0.1` (WSL2 localhost forwarding).

Last verified 2026-11-07: steps 2-3 on Ubuntu 24.04 (WSL) and Windows 11
(Python 3.12); `smoke.cjs` on Windows 11 with playwright-core + Edge. The
bundled-Chromium and `--with-deps` install path and macOS weren't run.
